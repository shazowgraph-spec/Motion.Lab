FAQ

Questions fréquentes

Les presets sont-ils compatibles avec mon logiciel de montage ? +

Oui. Les exports sont des fichiers MP4 (H.264) standard : Premiere Pro, DaVinci Resolve, CapCut, Final Cut, After Effects… tout ce qui accepte du MP4.

Quelle qualité d'export puis-je obtenir ? +

Jusqu'en 4K (3840×2160) à 60 fps, encodé H.264 High Profile. Le rendu se fait dans ton navigateur : un PC correct suffit.

Puis-je utiliser les exports commercialement ? +

Absolument — vidéos YouTube, Shorts, publicités, projets clients. Aucune attribution nécessaire, même avec le plan gratuit.

Faut-il internet pour exporter ? +

Une seule fois pour charger le site. Ensuite le rendu est 100 % local : rien n'est envoyé sur un serveur.

De nouveaux presets arrivent-ils régulièrement ? +

Oui, chaque semaine. Les membres du serveur Discord MOTIONLAB les reçoivent en avant-première, avec les notes de version.

Pourquoi demander une connexion Discord si c'est gratuit ? +

Parce qu'il n'y a aucun paiement à gérer : la connexion Discord sert de compte, et le serveur sert de canal pour les news, les nouveaux presets et l'entraide montage. C'est tout.
